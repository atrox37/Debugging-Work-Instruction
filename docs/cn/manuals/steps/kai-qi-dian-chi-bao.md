# 2. 开启电池包

**工序名称**：开启电池包

**工具/劳保用品**：一字螺丝刀、十字螺丝刀、绝缘手套

**作业步骤**

1. 卸下保护板，如图1所示。

![图2](/images/CN/2.png)

2. 打开断路器防水防尘盖。

![图3](/images/CN/3.png)

3. 断路器拨至 ON（闭合）位置，如图3所示。

![图4](/images/CN/4.png)

4. 短按电池启停按键，完成电池开机，此时 LED 指示灯亮起橙色。
5. 详情见 `Discover_Helios_314aH_OperationManual`。

**注意事项**

> 1. 注意指示灯状态。
> 2. 电池启动后，直流线缆及直流铜排均已带电，禁止触碰一切导体。
