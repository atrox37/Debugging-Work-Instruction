# 3. Start the inverter

**Process Name**: Start the inverter

**Tools / PPE**: Flat-head screwdriver, Phillips screwdriver, insulated gloves

**Procedure Steps**

1. Remove the inverter front cover as shown in Figure 1.

![Figure 5](/images/EN/5.png)

2. Open the two circuit breakers as shown in Figure 2.

![Figure 6](/images/EN/6.png)

3. Switch the PV switch to the ON position as shown in Figure 3.

![Figure 7](/images/EN/7.png)

4. Press the start button as shown in Figure 3 to start the inverter; the LCD screen will light up.
5. For details, refer to the Sol-Ark_18K-2P-LV_UserManual.

**Notes**

> 1. Before starting the inverter, the DC side is already live. Do not touch any conductors.
> 2. After starting the inverter, the entire system is live. Do not touch any conductors.
> 3. The operation for both inverters is the same; start them in master-slave sequence.
